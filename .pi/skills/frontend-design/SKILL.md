# Frontend Design

Use this skill for visual and interaction design work.

Read the relevant files under `references/` when the task needs deeper guidance.

## Core approach

1. Understand the product, user task, and current interface.
2. Identify the primary visual focal point.
3. Reduce unnecessary visual noise before adding decoration.
4. Improve hierarchy using spacing, type, alignment, contrast, and grouping.
5. Reuse the existing design system before inventing new primitives.
6. Keep interaction states obvious and accessible.
7. Prefer coherent, restrained design over generic AI-generated dashboard styling.
