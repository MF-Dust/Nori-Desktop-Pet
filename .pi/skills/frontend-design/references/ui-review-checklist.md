# UI Review Checklist

Before finishing a redesign, check:

- Is the primary action obvious?
- Is there one clear visual focal point?
- Is the text hierarchy easy to scan?
- Can any card be replaced by spacing and alignment?
- Are badges/chips actually useful?
- Are gradients/glows restrained?
- Are hover and focus states clear?
- Is keyboard interaction preserved?
- Are loading, empty, disabled, and error states covered?
- Did the change reuse the existing design system?
- Does the result look product-specific rather than template-generated?
