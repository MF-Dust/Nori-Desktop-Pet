# Visual Design

## Hierarchy

Every screen should have one dominant focal point.

Use these tools in roughly this order:
1. spatial grouping
2. typography
3. contrast
4. surface treatment
5. accent color
6. decoration

Do not use effects to compensate for weak hierarchy.

## Typography

Use size, weight, and spacing deliberately.
Avoid making every heading bold and every label prominent.
Secondary information should remain visually secondary.

## Color

Use accent color sparingly.
Reserve strong accent treatment for primary actions, active state, focus, and important feedback.
Neutral surfaces should do most of the structural work.

## Surfaces

Prefer whitespace and alignment before introducing another card.
Avoid nested cards unless they represent real hierarchy.
Avoid decorative borders that do not communicate grouping, state, or interaction.

## Avoid generic AI UI

Avoid:
- excessive glassmorphism
- excessive gradients
- glowing every interactive element
- oversized dashboard cards
- unnecessary badges
- repeated identical card grids
- multiple competing focal points
