# Layout and Density

## Desktop layout

Design for the actual application window, not for a marketing page.

Prefer:
- stable navigation
- clear content regions
- predictable scroll boundaries
- compact but readable controls
- consistent spacing rhythm

## Density

Information-heavy screens may be dense without feeling cluttered.

Use:
- alignment
- grouping
- consistent label/value patterns
- progressive disclosure

Avoid solving density by wrapping every group in a large padded card.

## Spacing

Use a consistent spacing scale.
Increase spacing between groups more than inside groups.
Do not rely on random margins to create hierarchy.
