# Interaction and Motion

## Interaction states

Every interactive element should have clear:
- default
- hover
- active
- focus-visible
- disabled
- loading, where relevant

## Motion

Prefer subtle motion:
- opacity transitions
- small position changes
- short state transitions

Avoid:
- constant decorative animation
- large hover scaling
- excessive pulsing
- unrelated simultaneous animations

Motion should clarify state or reinforce personality, not compete with content.
