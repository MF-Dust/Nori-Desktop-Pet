# Motion and Glow

Glow is part of Nori's identity, but it is a scarce visual resource.

Prefer glow for:
- character presence
- active navigation
- primary focus
- important interaction feedback

Avoid applying glow simultaneously to:
- cards
- buttons
- borders
- icons
- text
- background decorations

## Motion

Prefer:
- subtle opacity transitions
- small position transitions
- gentle state changes
- deliberate character-related animation

Avoid:
- constant decorative movement
- unnecessary pulsing
- large hover scaling
- multiple simultaneous animations

The desktop pet should remain the most alive element on the screen.
