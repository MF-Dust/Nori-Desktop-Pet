# Desktop App Patterns

Nori is a desktop application, not a responsive website.

Consider:
- finite window sizes
- resize behavior
- keyboard interaction
- persistent navigation
- scroll containment
- loading states
- error states
- empty states
- disabled states
- platform capability degradation

Prefer compact desktop density over oversized web spacing.

Settings screens should optimize scanability and grouping.
Chat should optimize conversation and immediate action.
Model management should prioritize current model state and preview.
Onboarding should minimize cognitive load and expose only the next necessary decision.
