# Nori Visual Language

## Identity

Nori should feel:
- calm
- intimate
- deep-ocean inspired
- futuristic without becoming cyberpunk noise
- character-centered
- polished but not corporate

The UI is a frame around the character, not the subject itself.

## Color behavior

Preserve the existing deep-sea palette.

Use cyan/teal mainly for:
- active navigation
- primary actions
- focus
- important interactive state
- character presence

Do not make every border, icon, text shadow, and background glow teal.

Neutral dark surfaces should provide most of the structure.

## Visual hierarchy

When the character is present, it should carry more visual weight than decorative UI.
Technical metadata should remain supportive and quiet.

## Avoid

- generic SaaS dashboard layouts
- oversized KPI-style cards
- excessive pill badges
- excessive glow
- excessive gradients
- multiple luminous borders
- decorative effects without interaction or hierarchy purpose
