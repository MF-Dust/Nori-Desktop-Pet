# Nori Desktop Pet 技术

| 模块              | 语言 / 技术              | 负责什么                                         |
| ----------------- | ------------------------ | ------------------------------------------------ |
| **桌宠主程序**    | **Rust + Tauri**         | 桌面程序/窗口调度/命令系统/内存数据库/日志   |
| **前端 UI**       | **TypeScript + Vue 3**   | 桌宠界面/聊天/设置/Live2D 显示(Vite / Vue Router / vue-i18n) |
| **Live2D**        | **TypeScript**           | `live2d-easy-control`(内置 Cubism SDK Core 5.1.0)+ 自定义 `asset://` 协议加载本地模型 |
| **后端网关**      | **Go**                   | 资源下载签名 URL(阿里云 OSS)/上游转发/请求日志/CORS; 默认端口 8084 |
| **本地存储/配置** | **Rust + SQLite**        | `nori.db` 存配置与首次初始化标记(rusqlite); 记忆库为后续扩展点 |
| **模型/资源管理** | **Rust + Go**            | 校验/经网关签名 URL 下载 zip/解压/列表/删除  |
| **云端 LLM**      | **HTTP / WebSocket API** | 调用 GPT 等模型; 当前已实现模型列表拉取与初始化接入 |
| **AI Agent**      | **TypeScript**(规划中) | Agent Loop/JSON 协议/Tool Calling/上下文       |
| **记忆系统**      | **TypeScript + SQLite**(规划中) | 短期/长期记忆/向量检索                  |
| **TTS Runtime**   | **Python**(规划中)     | GPT-SoVITS V2 Pro 推理                           |
| **GPT-SoVITS**    | **Python**(规划中)     | Nori TTS 模型                                    |
| **本地通信**      | **HTTP / WebSocket**(规划中) | 桌宠 ↔ TTS Worker                         |

## 核心流程

```mermaid
flowchart TD
    nori[Nori Desktop Rust+Tauri] --> vue[TypeScript + Vue 3]
    nori --> rust[Rust]
    vue --> l2d[Live2D: live2d-easy-control]
    rust --> sqlite[(SQLite 配置/记忆)]
    rust -- 校验/下载 --> go[Go 后端网关]
    go -- OSS 签名 URL --> oss[(阿里云 OSS)]
    oss --> dl[模型 zip 下载 / 解压]
    vue -. Agent(规划) .-> agent[AI Agent]
    agent -. 本地通信 .-> tts[TTS Worker Python(规划)]
```
